## Capstone Project

For my capstone, I revisited an Android Scheduler application built with Kotlin and Jetpack Compose, focusing on three areas of computer science:

- **Software Design and Engineering:** Refactored application components to improve maintainability, organization, and separation of responsibilities.
- **Algorithms and Data Structures:** Implemented scheduling conflict detection to prevent overlapping events while allowing back-to-back appointments.
- **Databases:** Enhanced Room database integrity through foreign keys, indexing, cascading deletion, and migration testing.
