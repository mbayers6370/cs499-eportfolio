01 / Design
Milestone Two / Software Design & Engineering

Structure that can grow.

Refactored oversized components and separated responsibilities, including moving logic into ViewModels. The goal was clearer maintainability and easier future development without changing the application's intended behavior.

Download narrative
02 / Logic
Milestone Three / Algorithms & Data Structures

Time, without conflicts.

Introduced interval-overlap detection using startA < endB && startB < endA. The logic catches overlapping and nested events while allowing events to begin exactly when another ends.

Download narrative
03 / Data
Milestone Four / Databases

Integrity by design.

Strengthened the Room database with foreign-key relationships, indexes, cascading deletion, and explicit migrations. Migration testing helped verify that existing records and collection relationships remained intact.
